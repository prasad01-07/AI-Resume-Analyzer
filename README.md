AI Resume Analyzer

Overview

AI Resume Analyzer is a Django-based web application that analyzes resumes and provides valuable insights to job seekers.

The system extracts text from uploaded PDF resumes, detects skills, calculates resume and ATS scores, identifies missing skills, recommends suitable jobs, predicts career paths, and generates downloadable PDF reports.

---

Features

- Resume Upload (PDF)
- PDF Text Extraction
- Skill Detection
- Resume Score Calculation
- ATS Score Analysis
- Resume Badge System
- Missing Skills Detection
- AI Suggestions
- Job Recommendations
- Career Prediction
- PDF Report Download

---

Tech Stack

Backend

- Python
- Django

Frontend

- HTML
- Bootstrap 5

Libraries

- PyPDF2
- ReportLab

Database

- SQLite3

---

Project Workflow

1. User uploads a resume.
2. Resume text is extracted from PDF.
3. Skills are detected from the extracted content.
4. Resume score is calculated.
5. ATS score is generated.
6. Missing skills are identified.
7. Career prediction is generated.
8. Job recommendations are displayed.
9. PDF report can be downloaded.

Installation

Clone Repository

git clone https://github.com/prasad01-07/AI-Resume-Analyzer.git

Move to Project Folder

cd AI-Resume-Analyzer

Create Virtual Environment

python -m venv venv

Activate Virtual Environment

Windows:

venv\Scripts\activate

Install Dependencies

pip install -r requirements.txt

Run Server

python manage.py runserver
